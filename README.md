# 🛠️ Proyectos y Prácticas de ASIR

Estos son algunos de los proyectos que he realizado durante el ciclo formativo de ASIR (Administración de Sistemas Informáticos en Red) en el colegio Tajamar

---

## 📚 Asignaturas de 1ero

### 📁 [ISO] Implantación de Sistemas Operativos
*Configuración, administración y mantenimiento de sistemas Windows y Linux.*
* 💻 **Prácticas destacadas:**
  * [Configuración de Arranque Dual](ISO/Configuración%20de%20Arranque%20Dual/)
  * [Preparación de Discos](ISO/Preparación%20de%20Discos/)

### 📁 [PAR] Planificación y Administración de Redes
*Diseño de topologías de red, direccionamiento IP y configuración de dispositivos.*
* 🌐 **Prácticas destacadas:**
  * Simulaciones de redes complejas en Cisco Packet Tracer.
  * Configuración de routing estático, dinámico (OSPF) y VLANs.
  * Análisis de tráfico y protocolos con Wireshark.

### 📁 [GBD] Gestión de Bases de Datos
*Diseño lógico, físico y administración de sistemas gestores de bases de datos.*
* 🗄️ **Prácticas destacadas:**
  * Modelado de diagramas Entidad-Relación (E/R) y paso a tablas.
  * Consultas avanzadas, subconsultas y optimización en MySQL/MariaDB y PostgreSQL.
  * Scripts de respaldo (backups) y automatización de mantenimiento.

### 📁 [LMSGI] Lenguajes de Marcas y Sistemas de Gestión de Información
*Creación de documentos web, sindicación de contenidos y almacenamiento de información.*
* 📄 **Prácticas destacadas:**
  * Diseño de páginas web con HTML5 y hojas de estilo CSS3.
  * Validación y transformación de datos con XML, DTD, XSD y XPath.
  * Configuración y despliegue de un CMS (WordPress / Moodle).

### 📁 [FH] Fundamentos de Hardware
*Componentes físicos, montaje, diagnóstico de averías y virtualización.*
* 🔌 **Prácticas destacadas:**
  * Configuración de entornos virtuales nativos y alojados (VirtualBox, VMware, KVM).
  * Análisis de rendimiento de hardware y soluciones RAID por software.
